# Эмулятор командной строки UNIX-подобной ОС

Мини-проект на Python, который реализует простой REPL-интерфейс командной строки. Он показывает, как формируется приглашение на основе текущего пользователя, имени узла и рабочего каталога, обрабатывает кавычки в аргументах и поддерживает основные команды-заглушки: `ls`, `cd` и `exit`.

## Что реализовано

- CLI-интерфейс в интерактивном режиме;
- формирование приглашения вида `username@hostname:cwd$ `;
- парсер аргументов через `shlex` для корректной обработки кавычек;
- заглушки для `ls` и `cd`;
- команда `exit` для завершения работы;
- набор тестов для проверки парсинга и команд.

## Требования

- Python 3.10+

## Запуск

```bash
python src/main.py
```

## Запуск тестов

```bash
python -m unittest discover -s tests -v
```

## Настройки запуска

Программа принимает путь к расположению VFS и путь к стартовому скрипту.
Значения параметров выводятся при запуске. На этапе 2 путь VFS только
принимается как настройка; загрузка файловой системы будет добавлена далее.

```bash
python src/main.py --vfs-path "vfs" --startup-script "scripts/startup_demo.txt"
```

Стартовый скрипт выполняет команды по порядку. Каждая команда выводится вместе
с приглашением эмулятора. Ошибочные команды сообщаются, пропускаются, и
выполнение продолжается. Команда `exit` завершает эмулятор.

Для демонстрации на Windows предусмотрены сценарии:

```bat
scripts\test_config.bat
scripts\test_startup_errors.bat
```

## Примеры использования

```text
$ python src/main.py
user@host:~$ ls -l /tmp
ls: команда вызвана с аргументи: ['-l', '/tmp']
user@host:~$ cd ..
cd: команда вызвана с аргументами: ['..']
user@host:~$ ls "hello world"
ls: команда вызвана с аргументами: ['hello world']
user@host:~$ exit
Выход.
```

## Структура проекта

- `src/main.py` — основной код эмулятора;
- `tests/test_main.py` — тесты;
- `scripts/` — стартовые скрипты эмулятора и демонстрационные `.bat`-файлы;
- `run.bat` — удобные команды запуска;
- `.gitignore` — игнорируемые служебные файлы.

## Команды run.bat

```bat
run.bat
run.bat test
run.bat --vfs-path "vfs" --startup-script "scripts\startup_demo.txt"
```
