# Эмулятор командной строки UNIX-подобной ОС

Мини-проект на Python, который реализует простой REPL-интерфейс командной строки. Он показывает, как формируется приглашение на основе текущего пользователя, имени узла и рабочего каталога, обрабатывает кавычки в аргументах и поддерживает основные команды-заглушки: `ls`, `cd`, `echo` и `exit`.

## Что реализовано

- CLI-интерфейс в интерактивном режиме;
- формирование приглашения вида `username@hostname:cwd$ `;
- парсер аргументов через `shlex` для корректной обработки кавычек;
- заглушки для `ls`, `cd` и `echo`;
- команда `exit` для завершения работы;
- набор тестов для проверки парсинга и команд.

## Требования

- Python 3.10+

## Установка

```bash
python -m venv .venv
# Linux/macOS
source .venv/bin/activate
# Windows
.venv\Scripts\activate
pip install -r requirements.txt
```

## Запуск

```bash
python src/main.py
```

## Запуск тестов

```bash
pytest -q
```

## Примеры использования

```text
$ python src/main.py
user@host:~$ ls -l /tmp
ls: команда вызвана с аргументи: ['-l', '/tmp']
user@host:~$ cd ..
cd: команда вызвана с аргументами: ['..']
user@host:~$ echo "hello world"
hello world
user@host:~$ exit
Выход.
```

## Структура проекта

- `src/main.py` — основной код эмулятора;
- `tests/test_main.py` — тесты;
- `Makefile` — удобные команды запуска;
- `.gitignore` — игнорируемые служебные файлы.

## Команды Makefile
