# Эмулятор командной строки UNIX-подобной ОС

Мини-проект на Python (вариант 8): консольный эмулятор оболочки с
интерактивным REPL, настройкой через параметры командной строки и
виртуальной файловой системой (VFS). Каталог-источник VFS читается в память;
исходные файлы на диске не изменяются.

## Возможности и настройки

- приглашение `username@hostname:/путь$` формируется из данных реальной ОС и текущего каталога VFS;
- разбор аргументов с поддержкой кавычек (`echo "two words"`);
- `ls [-l] [путь...]` — содержимое каталогов VFS (`-l`: тип и размер);
- `cd [путь]` — смена текущего каталога VFS (без аргумента — корень `/`);
- `whoami` — имя пользователя реальной ОС;
- `history` — пронумерованная история введенных команд;
- `tail [-n N] файл...` — последние N строк (по умолчанию 10) файлов VFS;
- `echo` выводит аргументы, `exit` завершает работу;
- `vfs-info` — служебная команда: источник и число файлов и каталогов VFS;
- параметр `--vfs-path` — каталог на диске, который загружается как VFS;
- параметр `--startup-script` — файл с командами, выполняемыми при запуске.

При запуске все заданные параметры выводятся на экран (отладочный вывод).

Стартовый скрипт выполняет команды по порядку. Перед каждой командой выводится
приглашение эмулятора и сама строка. Ошибочные строки пропускаются с
сообщением об ошибке, выполнение продолжается; `exit` завершает сценарий и
приложение.

VFS должна быть каталогом. Если путь не найден или вместо каталога передан
файл, приложение сообщает об ошибке загрузки и завершается с кодом 1.
Без `--vfs-path` создается пустая VFS.

## Требования

- Python 3.10+
- Внешние библиотеки не требуются.

## Сборка и тесты

```bash
make run
make test
```

Без `make`:

```bash
python src/main.py
python -m unittest discover -s tests -v
```

## Примеры использования

```bash
python src/main.py --vfs-path "tests/fixtures/vfs_nested" --startup-script "scripts/startup_all.txt"
```

Сценарии демонстрации для Windows:

```bat
scripts\test_config.bat
scripts\test_startup_errors.bat
scripts\test_vfs_files.bat
scripts\test_vfs_nested.bat
scripts\test_vfs_all.bat
scripts\test_vfs_errors.bat
scripts\test_commands.bat
```

Тестовые VFS в `tests/fixtures`: `vfs_minimal` (один файл), `vfs_files`
(несколько файлов), `vfs_nested` (три уровня вложенности). Скрипты `startup_commands.txt` и `startup_files.txt`
проверяют все режимы `ls`, `cd`, `whoami`, `history`, `tail` и обработку
ошибок.

## Структура

- `src/main.py` — эмулятор, конфигурация и загрузчик VFS;
- `tests/test_main.py`, `tests/test_commands.py` — автоматические тесты;
- `tests/fixtures/` — тестовые источники VFS;
- `scripts/` — стартовые скрипты эмулятора и сценарии для Windows;
- `Makefile` — команды запуска и тестирования;
- `.gitignore` — исключения для локальных артефактов.
